XRay

Look at material without a profile attached. Pick a source group, type or paste, and XRay lists clean links for you to choose from.

Sources

XRay is a launcher, not a browser engine. It can’t block trackers on the pages you visit, so open its links in a browser with a blocker such as uBlock Origin, ideally in a private window so your logins don’t come along.

Enter lists the ticked sources. Shift+Enter or Open all selected also opens them as tabs, which works only if you allow pop-ups for this file. After the first list, it updates as you type or change ticks.

XRay remembers only your last group and ticks, on this device. It never stores your searches and the page can’t send anything anywhere. Search addresses can change; each one is a single line in the TABS list in this file.
